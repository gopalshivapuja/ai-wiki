# Hugging Face

**Hugging Face** is the premier platform and community for open-source AI, hosting models, datasets, and machine learning applications (Spaces).

---

## Core Ecosystem & Libraries

- **`transformers`**: De facto Python library for loading, fine-tuning, and running inference on [[transformer-architecture|Transformer]] models across PyTorch and TensorFlow.
- **`peft`**: Standard library implementing [[fine-tuning-and-alignment|LoRA, QLoRA]], and prefix tuning.
- **`datasets` & `accelerate`**: Efficient data streaming and multi-GPU distributed training utilities.
- **Hub**: Hosts over 500,000 open-weights models (including [[meta-ai|LLaMA]], Mistral, DeepSeek).
